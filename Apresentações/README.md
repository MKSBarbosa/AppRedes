# Apresentações

Slides utilizados nas aulas/apresentações do estágio docência.

## Arquivos

### Laboratórios de rede (Packet Tracer)
- **`Lab Packet Tracer.pdf`** — roteiro de laboratório de configuração de rede no Cisco Packet Tracer.
- **`Lab Packet Tracer 2.pdf`** — segundo roteiro de laboratório no Cisco Packet Tracer.

### Virtualização
- **`Era da Virtualização.pdf`** — introdução aos conceitos de virtualização.
- **`Configurando uma Máquina Virtual.pdf`** — passo a passo para configuração de uma máquina virtual, usada como ambiente para os demais exemplos práticos.

### Sockets, Web e Segurança
- **`Introdução à programação com sockets.pdf`** — introdução aos conceitos de sockets e comunicação cliente-servidor, base para os exemplos em [`Cliente-Servidor/`](../Cliente-Servidor).
- **`Certificados e Servidor Web.pdf`** — introdução a servidores Web, certificados digitais e HTTPS, base para os exemplos em [`Web/`](../Web) e [`Segurança/`](../Segurança).
- **`Introdução ao Wireshark.pptx.pdf`** — introdução ao Wireshark, ferramenta de captura e análise de pacotes de rede.

### Redes P2P
- **`Introdução à P2P.pdf`** — introdução a redes peer-to-peer (P2P).
- **`Introdução à DHT.pdf`** — introdução a Tabelas de Hash Distribuídas (DHT), usadas em redes P2P para localização descentralizada de recursos.
